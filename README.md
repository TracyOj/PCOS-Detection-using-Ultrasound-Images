# 🏥 PCOS Detection using Ultrasound Images

> **A tool leveraging Deep Learning (CNN) to identify Polycystic Ovary Syndrome (PCOS) from medical ultrasound imagery.**

## 📖 Overview
>Polycystic Ovary Syndrome (PCOS) is a hormonal disorder common among women of reproductive age. Early diagnosis is crucial but manual interpretation of ultrasound images can be time-consuming and prone to error.
> <img width="1442" height="775" alt="image" src="https://github.com/user-attachments/assets/9f62bbc9-a5ce-46f0-abd9-3ec6cd72a093" />
This project implements a **Convolutional Neural Network (CNN)** to automatically classify ultrasound images as "Infected" (PCOS positive) or "Not Infected" (Healthy). The model aims to assist medical professionals by providing a rapid, secondary diagnostic opinion.
>
> ## 📂 Dataset
The dataset used for this project is sourced from Kaggle: [PCOS Detection using Ultrasound Images](https://www.kaggle.com/datasets/anaghachoudhari/pcos-detection-using-ultrasound-images/data).
